# M1.7 SSRF Guard Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upstream destinations are checked twice: when an API is saved (the management API rejects a blocked host with a 422) and at connect time (the gateway's HTTP transport resolves DNS, validates every resolved IP, and connects to the validated IP, so DNS rebinding cannot swap it). A blocked destination raises `JV_DESTINATION_BLOCKED`.

**Architecture:** `jarvis_core.ssrf` holds the pure rules (host parsing, IP classification, the admin allowlist policy, resolve-and-validate) so the API and the gateway share one implementation. `jarvis_gateway.upstream` provides `PinnedTransport`, an `httpx` transport whose network backend does resolution, validation and connection in one step; the URL host is untouched, so SNI and the `Host` header stay as the client set them. The API calls the same rules in its save path.

**Tech Stack:** stdlib `ipaddress`, `socket`, `asyncio`; `httpx==0.28.1` and `httpcore==1.0.9` (both already in `uv.lock`; new runtime pins for `services/gateway`).

**Spec:** `docs/SPEC.md` §4.13, §4.3 step 8, §17 (security tests); `docs/IMPLEMENTATION.md` M1.7; requirements REQ-3-4, REQ-4.13-1 to -7, REQ-17-2.

**Prerequisite:** M1.6 merged (`937a936`). Branch `feat/m1.7-ssrf-guard` from `main`.

## Global Constraints

- "Upstream hosts are resolved at config save and **re-validated at connect time**. The connection is pinned to the validated IP, which prevents DNS-rebinding attacks." (SPEC §4.13)
- "**Blocked by default:** loopback, RFC 1918, link-local (including `169.254.169.254`), CGNAT, IPv6 ULA and link-local, multicast, and the JARVIS containers themselves."
- "An admin-managed allowlist (CIDRs or hosts) permits internal upstreams. Only `https` upstream URLs are allowed by default. Plain `http` requires the host to be on the allowlist."
- "Upstream redirects are not followed by default. When following is enabled, every hop is SSRF-checked." (SPEC §17)
- A blocked destination returns `JV_DESTINATION_BLOCKED` (403, `jarvis_core.errors.DestinationBlockedError`).
- Dependencies pinned exactly. Core ≥ 95% line / 90% branch, gateway ≥ 90% / 85%, api ≥ 85% / 75%, no drop over 1 point vs `main`. Core and gateway are mypy-strict. Every test has one type marker; requirement tests carry `@pytest.mark.req(...)`.
- No Claude attribution in commits or the PR body (user memory).

## Decisions made here (not in the spec)

- **Allowlist source (for now): the environment.** `JARVIS_SSRF_ALLOWLIST` is a comma- or space-separated list of CIDRs and host names, read by both the api and the gateway. The admin-managed settings page and its storage arrive in M4.11, which will replace the env source; the policy object does not change. Default empty. *Cost if wrong: a later migration of where the list comes from.*
- **Host entries are exact** (case-insensitive, trailing dot ignored); an allowlisted host may resolve to any address. A CIDR entry allows any host that resolves into it. Plain `http` needs the host itself on the list (a host entry, or an IP literal inside an allowlisted CIDR).
- **JARVIS containers.** `JARVIS_INTERNAL_HOSTS` (default `gateway,api,worker,postgres,redis`) names them. Those names are blocked as destinations, and the IPs they resolve to are blocked even when a broad allowlist CIDR covers the Docker network. Their resolution is cached for 30 s so connects stay cheap. *The allowlist cannot override this.*
- **Block list.** Explicit networks, not `ipaddress.is_global` (its answers changed across Python 3.12 patch releases): `0.0.0.0/8`, `10.0.0.0/8`, `100.64.0.0/10`, `127.0.0.0/8`, `169.254.0.0/16`, `172.16.0.0/12`, `192.0.0.0/24`, `192.0.2.0/24`, `192.168.0.0/16`, `198.18.0.0/15`, `198.51.100.0/24`, `203.0.113.0/24`, `224.0.0.0/4`, `240.0.0.0/4`, `::/128`, `::1/128`, `fc00::/7`, `fe80::/10`, `ff00::/8`, `2001:db8::/32`. IPv6 forms that embed an IPv4 address (`::ffff:a.b.c.d`, `64:ff9b::/96`, `2002::/16` 6to4, IPv4-compatible `::a.b.c.d`) are classified by the embedded IPv4.
- **Host forms.** Host names are lower-cased, a trailing dot is dropped, IDNA-encoded to ASCII, and rejected if empty, with whitespace or control characters, or an IPv6 zone id. Hosts that look numeric (digits, dots, `x`, hex digits) are parsed with `socket.inet_aton` semantics, so `2130706433`, `0177.0.0.1`, `0x7f.1` and `127.1` are treated as the IPv4 address the OS would connect to. `localhost` and `*.localhost` are blocked by name.
- **Unresolvable host.** At save time an unresolvable host is **accepted** (connect time is the enforcement, and the quickstart's `api.weather.example` does not resolve); a host that resolves to any blocked address is rejected. At connect time an unresolvable host is a connection failure, not `JV_DESTINATION_BLOCKED`.
- **Every resolved IP must pass.** If any address of a name is blocked, the whole name is blocked. The connection tries the validated addresses in resolver order.
- **Save-time error.** The management API answers 422 with field path `body.base_url` and the fixed message `destination is not allowed` (no resolved addresses echoed). Gateway connect time raises `DestinationBlockedError("destination is not allowed")`.
- **Redirects.** The transport validates every connection, so enabling `follow_redirects` on a client using it checks every hop. Redirects stay off by default (httpx default); M1.8 builds the client.
- **Not wired into the request path yet.** M1.8 builds the pooled client on `PinnedTransport`. M1.7 delivers the transport, the rules, the save-time check, and tests.
- **Existing tests and compose.** The test compose stack sets `JARVIS_SSRF_ALLOWLIST=mock-upstream` on `api` and `gateway`, because its tests save `http://mock-upstream:8080`. Integration tests that construct `Services` pass a stub resolver.

## Review Focus

- Decimal, octal, hex and short IPv4 hosts, IPv4-mapped/6to4/NAT64 IPv6, bracketed IPv6, zone ids, trailing-dot and upper-case `LOCALHOST`, IDNA look-alikes: all blocked or rejected (Task 1, 4).
- A name that returns one public and one private address: blocked (Task 1).
- DNS rebinding: public at save, private at connect, blocked (Task 2).
- A redirect to `169.254.169.254` or to an `http` URL of a non-allowlisted host: blocked on each hop (Task 2).
- An allowlist CIDR that covers the Docker network must not unblock the JARVIS containers (Task 1).
- SNI and `Host` stay the original host name when connecting to the pinned IP (Task 2).
- No resolved address, allowlist entry or internal host list appears in an error message or log (Task 4).

### Task 1: Rules in `jarvis_core.ssrf`

**Files:** Create `packages/core/src/jarvis_core/ssrf.py`; tests `packages/core/tests/unit/test_ssrf.py`.

**Interfaces (produces):**
- `Resolver = Callable[[str, int], Awaitable[Sequence[str]]]`; `async def system_resolver(host: str, port: int) -> list[str]` (uses `loop.getaddrinfo`, deduplicated, order kept).
- `class HostNotResolved(Exception)`.
- `@dataclass(frozen=True) class SsrfPolicy: allow_networks: tuple[IPv4Network | IPv6Network, ...] = (); allow_hosts: frozenset[str] = frozenset(); internal_hosts: frozenset[str] = DEFAULT_INTERNAL_HOSTS; @classmethod from_env(cls, env: Mapping[str, str]) -> SsrfPolicy` (raises `ValueError` naming the variable and the bad entry index, never the value).
- `def normalize_host(host: str) -> str | IPv4Address | IPv6Address` (raises `DestinationBlockedError`).
- `def ip_is_blocked(ip: IPv4Address | IPv6Address) -> bool`.
- `def check_destination_name(scheme: str, host: str, policy: SsrfPolicy) -> bool` — no DNS: raises `DestinationBlockedError` for a bad scheme, bad host form, `localhost`, an internal host name, or `http` for a host not on the allowlist; returns whether the host is on the allowlist.
- `class DestinationResolver: def __init__(self, policy: SsrfPolicy, resolver: Resolver = system_resolver, clock: Clock | None = None)`; `async def resolve(self, host: str, port: int, *, on_allowlist: bool) -> list[str]` — resolves the name (or uses the IP literal), applies the rules to every address, caches the internal-host addresses for 30 s, returns the validated addresses; raises `HostNotResolved` for no addresses and `DestinationBlockedError` for any blocked address.
- `class DestinationChecker: def __init__(self, destinations: DestinationResolver)`; `async def check_save(self, base_url: str) -> None` — parses the URL, runs `check_destination_name` and `resolve`, swallows `HostNotResolved`.
